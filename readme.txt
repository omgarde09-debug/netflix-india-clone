# Netflix India Clone

This is my first frontend development project, built using **HTML5 and CSS3**.

The project recreates the Netflix India website design, inspired by its 2026 interface. It focuses on responsive layouts, modern styling, and smooth CSS transitions.

## Live Demo

[View Netflix India Clone]



## Built With

- HTML5
- CSS3
  - Flexbox
  - Media Queries
  - Transitions

## Features

- Responsive design (Mobile, Tablet, and Desktop)
- Trending Now scrollable card section with number overlays
- Smooth hover animations and transitions
- Curved section separator
- Frequently Asked Questions (FAQ) section
- Multi-column footer layout

## What I Learned

- Creating layouts using CSS Flexbox
- Implementing CSS transitions and hover effects
- Building responsive designs using media queries
- Understanding Z-index and CSS positioning
- Working with CSS gradients and overlays
